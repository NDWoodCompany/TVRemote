TVRemote Native S20 - v2.2
===========================

Sửa lỗi build theo log mới nhất:
- Thêm import android.view.Gravity trong Main.kt.
- Không thay đổi logic điều khiển hoặc cấu hình build.

Cập nhật trực tiếp trên GitHub bằng Edge, không cần cài CLI/Git và không cần đồng bộ dự án:
1. Mở repository NDWoodCompany/TVRemote trên GitHub.
2. Mở đúng file: android/app/src/main/kotlin/com/ndwood/tvremote/Main.kt
3. Nhấn biểu tượng bút chì (Edit this file).
4. Mở file Main.kt.txt được gửi kèm, sao chép toàn bộ nội dung.
5. Dán đè toàn bộ nội dung trong trình sửa file GitHub.
6. Nhấn Commit changes và xác nhận commit vào nhánh đang dùng để build (thường là main).
7. Vào Actions, chạy lại workflow hoặc chờ workflow tự chạy.

Lưu ý:
- Không tải ZIP này lên thư mục gốc repository như một file ZIP. GitHub sẽ chỉ lưu ZIP, không tự giải nén và thay thế mã nguồn.
- Phải thay nội dung đúng file Main.kt theo đường dẫn ở trên.
- ZIP chứa toàn bộ mã nguồn dự án; Main.kt.txt là file thuận tiện để cập nhật riêng trên giao diện GitHub.
- Đã kiểm tra cấu trúc ZIP và xác nhận Main.kt có import android.view.Gravity.
- Chưa thể xác nhận build APK thành công nếu chưa chạy workflow trên GitHub.
